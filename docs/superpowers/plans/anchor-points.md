### UPSERT Pattern (UPDATE-then-INSERT)
**File:** repo.go:81–115 (`UpsertCandidatos`)

**Why UPSERT via EXECUTE BLOCK:** Firebird's MERGE cannot bind params in USING SELECT (SQL error -804). EXECUTE BLOCK sidesteps this by batching multiple rows in a single statement.

**Chunk size:** 20 rows per EXECUTE BLOCK (560 params, 40 relation contexts, below Firebird's 256 limit).

**Key invariant:** UPDATE clause omits `EN_CONTROL` and `COHORTE_FECHA` so they survive across refreshes; only new inserts set them.

**Pattern verbatim (repo.go:125–148):**
```go
func buildUpsertBlock(chunk []*domain.WinbackCandidato) (string, []any) {
	n := len(chunk)
	args := make([]any, 0, n*28)

	var header strings.Builder
	var body strings.Builder

	_, _ = header.WriteString("EXECUTE BLOCK (\n")
	_, _ = body.WriteString("AS\nBEGIN\n")

	for i, c := range chunk {
		p := fmt.Sprintf("p%d", i)
		if i > 0 {
			_, _ = header.WriteString(",\n")
		}
		appendUpsertParamDecls(&header, p)
		appendUpsertBodyStmt(&body, p)
		args = appendUpsertArgs(args, c)
	}

	_, _ = header.WriteString("\n)")
	_, _ = body.WriteString("END")

	return header.String() + "\n" + body.String(), args
}
```

### Read Pattern (GetCandidato)
**Signature (via WinbackRepo interface):** Returns `*domain.WinbackCandidato` or `domain.ErrWinbackCandidatoNotFound`.

**How Firebird time is handled:**
- **Write:** UUID generated by Go (newID()); `firebird.ToWallClock(now)` converts UTC time.Time to Firebird TIMESTAMP
- **Read:** `firebird.ScanUTCTime()` reads TIMESTAMP column into time.Time, normalized to UTC

	requireFBEnv(t)

		err := repo.UpsertCandidatos(ctx, []*domain.WinbackCandidato{c})

		page, err := repo.ListCandidatos(ctx, outbound.ListWinbackParams{})

		require.GreaterOrEqual(t, page.Total, 1)

		// Find our row and assert round-trip...
	})

- Wraps test code in a transaction that always rolls back
- Injects the transaction into ctx so all DB calls via `firebird.GetQuerier(ctx, pool.DB)` honor it
- Shared dev DB never accumulates test data
- Test DB rows must use negative clienteID (unlikely to collide with production)

- `FB_DATABASE` env var set to dev Firebird database path
- Migration 000035 must be applied (test skips cleanly otherwise)
